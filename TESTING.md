# Тестирование

Для запуска быстрых unit-тестов Docker не нужен:

```shell
./gradlew test
```

Интеграционные тесты запускают PostgreSQL 15 через Testcontainers, поэтому для них должен быть доступен Docker:

```shell
./gradlew integrationTest
```

Полная локальная проверка совпадает с проверкой в GitHub Actions:

```shell
./gradlew check
```

Интеграционный набор проверяет миграции Liquibase на настоящем PostgreSQL, JWT и разграничение ролей, конкурентную попытку занять последнее место, а также аутентификацию и персональные сообщения STOMP/WebSocket. Ошибки и пустые ответы внешнего OSRM проверяются unit-тестами без сетевых запросов.
